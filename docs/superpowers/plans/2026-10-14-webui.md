# yt-dlp 可视化网页（webui）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 本机浏览器里的可视化页面，覆盖 yt-dlp 全部参数，常用操作一键完成，执行结果与命令行一致。

**Architecture:** Flask 后端从 `yt_dlp.options.create_parser()` 自动生成参数表单描述；表单状态以「参数名 → 值」保存，拼成参数列表后以子进程运行 `python -m yt_dlp`（不经 shell），逐行解析带标记的进度输出，经 SSE 推给单文件原生 JS 页面。

**Tech Stack:** Python 3.14、Flask 3.1.3、imageio-ffmpeg（已装）、pytest（开发用，Task 1 安装）、原生 HTML/CSS/JS。

**Spec:** `docs/superpowers/specs/2026-10-14-webui-design.md`

## Global Constraints

- 所有代码在 `webui/`（Python 包，含 `__init__.py`），测试在 `webui/tests/`；不修改 `yt_dlp/` 下任何文件。
- 从仓库根目录运行：`python -m webui.app`；测试：`python -m pytest webui/tests -q`。
- 只监听 `127.0.0.1`；默认端口 `8765`，被占用时取系统分配的空闲端口。
- 下载目录默认为仓库根目录下的 `downloads/`。
- 子进程一律 `subprocess.Popen(list, shell=False)`，`stdin=subprocess.DEVNULL`，环境变量加 `PYTHONIOENCODING=utf-8`、`PYTHONUTF8=1`，stdout 与 stderr 合并，按 UTF-8 解码（`errors="replace"`）。
- 页面文案为中文；yt-dlp 参数说明保留英文原文。
- 参数总数、分组数一律运行时从 parser 读取，不写死。实测当前：16 组、250 个可见参数（`help != optparse.SUPPRESS_HELP`）。
- 不新增运行时依赖。
- 每个 Task 完成后提交到 `webui` 分支，提交信息以 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` 结尾。

## Review Focus

1. **中文标题/文件名**：yt-dlp 输出含中文时进度和成品路径不能乱码 → Task 3 用含中文的假子进程输出测试。
2. **分享文字里的链接**：抖音分享文案链接后紧跟中文/空格/符号；一段文字里多个链接；完全没有链接 → Task 2 `extract_urls` 测试，没有链接时接口返回 400 和中文提示（Task 4）。
3. **取消正在合并的任务**：yt-dlp 会再起 ffmpeg 子进程，取消必须结束整棵进程树 → Task 3 用「父进程再起子进程」的假命令测试。
4. **成品文件路径穿越**：`/files/../CLAUDE.md` 之类请求必须 404 → Task 4 测试。
5. **用户自己填了 `-P`、`--ffmpeg-location`、`--quiet`**：自填的 `-P`/`--ffmpeg-location` 不被覆盖；用户勾了 `--quiet` 也仍能拿到进度 → Task 2 测试 `build_args` 内部参数放在用户参数之后且 `--progress` 始终存在。

from yt_dlp.options import create_parser
from webui.options_schema import build_schema, HIDDEN_KEYS, GROUP_TITLES_ZH

def _all(schema): return [o for g in schema["groups"] for o in g["options"]]

def test_counts_match_parser():
    p = create_parser()
    visible = [o for g in p.option_groups for o in g.option_list
               if o.help != optparse.SUPPRESS_HELP]

### Task 3: 下载任务与解析预览 `tasks`

**Files:**
- Create: `webui/tasks.py`
- Test: `webui/tests/test_tasks.py`

**Interfaces:**
- Consumes: `build_args`, `parse_line`, `explain_error`（Task 2）
- Produces:
  - `YTDLP_CMD: list[str] = [sys.executable, "-m", "yt_dlp"]`

import sys, os, time, textwrap
from webui.tasks import TaskManager, probe, ProbeError

def fake(tmp_path, body):
    f = tmp_path / "fake.py"; f.write_text(textwrap.dedent(body), encoding="utf-8")
    return [sys.executable, str(f)]

def wait_done(t, s=10):
    end = time.time() + s
    while t.status == "running" and time.time() < end: time.sleep(0.05)

def test_progress_title_file_chinese(tmp_path):
    cmd = fake(tmp_path, '''
        print('WEBUI_TITLE 一站式创作Agent', flush=True)
        print('WEBUI_PROGRESS {"status":"downloading","downloaded_bytes":1,"total_bytes":2}', flush=True)
        print('WEBUI_FILE D:/dl/秋芝.mp4', flush=True)
    ''')
    t = TaskManager(cmd=cmd, cwd=str(tmp_path)).start({}, ["https://x"], downloads_dir=str(tmp_path), ffmpeg_path=None)
    wait_done(t)
    assert t.status == "finished" and t.title == "一站式创作Agent"
    assert t.files == ["D:/dl/秋芝.mp4"] and t.progress["percent"] == 50.0
    assert [e["i"] for e in t.events] == list(range(len(t.events)))

def test_error_exit_sets_hint(tmp_path):
    cmd = fake(tmp_path, '''
        import sys; print("ERROR: Unsupported URL: https://x", flush=True); sys.exit(1)
    ''')
    t = TaskManager(cmd=cmd, cwd=str(tmp_path)).start({}, ["https://x"], downloads_dir=str(tmp_path), ffmpeg_path=None)
    wait_done(t)
    assert t.status == "error" and "不支持" in t.error_hint

def test_cancel_kills_tree_and_cleans_part(tmp_path):
    marker = tmp_path / "child.pid"
    part = tmp_path / "v.mp4.part"
    cmd = fake(tmp_path, f'''
        import subprocess, sys, time
        c = subprocess.Popen([sys.executable, "-c", "import time; time.sleep(60)"])
        open(r"{marker}", "w").write(str(c.pid))
        open(r"{part}", "w").write("x")
        import json
        print("WEBUI_PROGRESS " + json.dumps({{"status": "downloading", "downloaded_bytes": 1, "filename": r"{part}"}}), flush=True)
        time.sleep(60)
    ''')
    m = TaskManager(cmd=cmd, cwd=str(tmp_path))
    t = m.start({}, ["https://x"], downloads_dir=str(tmp_path), ffmpeg_path=None)

- [ ] **Step 3: 实现 `webui/tasks.py`**

- 每个任务一个读取线程：逐行读合并后的输出，`parse_line` 后追加事件并更新 `title/progress/files`；用 `threading.Condition` 通知 `wait_events`。
- 进程结束：退出码 0 → `finished`；被取消 → `cancelled`；否则 `error`，`error_hint = explain_error(全部日志文本)`。
- 取消：Windows 用 `subprocess.run(["taskkill", "/T", "/F", "/PID", str(pid)])` 结束整棵进程树；之后对进度事件里出现过的每个 `filename`，删除 `filename`（若以 `.part` 结尾）、`filename + ".part"`、`filename + ".ytdl"` 中存在的文件。
- `probe`：运行 `cmd + ["-J", "--flat-playlist", "--no-warnings", url]`（`cookies_browser` 非空时加 `--cookies-from-browser <值>`），`timeout` 超时 → `ProbeError("解析超时（60 秒），可以重试", None)`（秒数用实际 timeout）；退出码非 0 → `ProbeError(最后一行 ERROR 文本, explain_error(输出))`；`entries` 下标从 1 开始。

**Files:**

页面结构与行为（按 spec「页面」一节）：

- **全局状态** `form = {}`（表单状态格式见上），任何控件改动 → 更新 `form` → 300ms 防抖调用 `/api/preview-command` 刷新命令预览 → 同步两处控件显示。
- **常用区**控件与 `form` 的映射（写死在页面里）：

| 控件 | 写入 `form` |
|---|---|
| 画质「最佳」 | 删除 `--format`、`--extract-audio`、`--audio-format` |

| 「720p」 | `--format = "bv*[height<=720]+ba/b[height<=720]"` |
| 「只要音频 mp3」 | 删除 `--format`；`--extract-audio = true`、`--audio-format = "mp3"` |
| 下载字幕 | `--write-subs = true`、`--sub-langs = ["zh.*", "en.*"]` |
| 嵌入封面 | `--embed-thumbnail = true` |
| 嵌入元数据 | `--embed-metadata = true` |
| Cookie 来源 不用/Edge/Chrome/Firefox | 删除或 `--cookies-from-browser = "edge"/"chrome"/"firefox"`；选中时在旁边显示「请先完全关闭该浏览器」 |
| 合集勾选 | 勾选的 `index` 用逗号连接 → `--playlist-items`；全选时删除该键 |

- **解析**：`POST /api/probe`（`cookies_browser` 取 `form["--cookies-from-browser"]`），显示封面、标题、作者、时长（`mm:ss` / `h:mm:ss`）；有 `entries` 时显示带复选框的列表（默认全选）；失败显示 `error` 和 `hint`。
