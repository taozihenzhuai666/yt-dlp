# yt-dlp 可视化网页（webui）设计

日期：2026-10-14 · 分支：`webui`（从 `master` 拉出）

## 目标

在本机浏览器里用可视化页面完成 yt-dlp 能做的**所有事**：常用操作一键完成，其余全部参数都能在页面上配置，执行结果与命令行完全一致。

### 成功标准

1. 双击 `webui/启动网页.bat`，浏览器自动打开页面。
2. 粘贴链接（或整段分享文字）→ 解析出封面、标题、作者、时长、合集列表 → 选画质 → 下载 → 页面显示实时进度 → 下载完成后能在页面里播放。
3. yt-dlp 的全部参数（当前 295 个，17 组）都能在「高级设置」里找到、搜索、填写，并且 `git pull upstream master` 后新增的参数**不改代码就会自动出现**。
4. 页面上始终显示与当前设置等价的命令行，可一键复制。

### 范围

- **只在本机运行**，监听 `127.0.0.1`，不做登录，不限制参数。
- **不做**：用户登录、公网部署、参数白名单、任务历史持久化、多语言切换、自动剪辑。
- 以后要上公网，另做「公网模式」（登录 + 危险参数白名单 + 路径限制），不在本设计范围内。

## 方案选择

| 方案 | 结论 |
|---|---|
| ① 从 yt-dlp 自身的参数定义自动生成表单，后台以子进程运行命令行 | **采用**：功能与命令行完全一致，官方新增参数自动跟进 |
| ② 每个参数手写控件 | 不采用：295 个参数工作量大，官方更新后对不上 |
| ③ 用现成开源网页版（如 MeTube） | 不采用：只覆盖常用功能，达不到「全部功能」 |

## 结构

所有代码放在 `webui/`，不改 yt-dlp 本身的代码。

```
webui/
  app.py              Flask 后端：页面、接口、任务管理、SSE 推送
  options_schema.py   从 yt-dlp 的参数定义生成表单描述（JSON）
  runner.py           表单值 → 命令行参数列表；运行子进程；解析进度；取消
  static/index.html   页面（单文件，原生 JS，无打包工具）
  启动网页.bat         启动后端并打开浏览器
  tests/            pytest 测试（不联网，与官方 test/ 分开）
```

依赖：Flask（本机已装 3.1.3）、`imageio-ffmpeg`（本机已装，提供 ffmpeg）。不新增其他依赖。

### options_schema.py

- 调用 `yt_dlp.options.create_parser()`，遍历 `parser.option_groups`，为每个参数输出：`dest`、长短参数名、类型、`choices`、`metavar`、默认值、英文 `help`、所在分组。
- 类型映射：
  - `store_true` / `store_false` / `store_const` → 勾选框
  - 有 `choices` → 下拉框
  - `append` 或可重复的 callback 参数 → 可增减多行的输入框
  - 其余 → 单行输入框（`metavar` 作占位提示）
- 17 个分组名翻成中文；参数说明保留英文原文。
- 隐藏非下载用途的参数：`--help`、`--version`、`--update`/`-U`、`--update-to`。
- 别名分组（Aliases）里的参数展开成其实际含义后照常显示。

### runner.py

- `build_args(form) -> list[str]`：把表单值转成参数列表，只输出与默认值不同的参数，固定追加：
  - `--ffmpeg-location <imageio_ffmpeg 路径>`（用户未填写时）
  - `-P downloads`（用户未填写时）
  - `--newline --progress-template "download:WEBUI_PROGRESS %(progress)j"`
  - `--print "after_move:WEBUI_FILE %(filepath)s"`
- `build_command_preview(form) -> str`：生成供显示和复制的命令行（不含上面的内部参数）。
- 运行：`subprocess.Popen([sys.executable, "-m", "yt_dlp", *args, *urls])`，**不经过 shell**；工作目录是仓库根目录；标准输入关闭。
- 逐行读取输出：`WEBUI_PROGRESS` 行解析为进度（百分比、速度、剩余时间、已下载/总大小），`WEBUI_FILE` 行记录成品路径，其他行进入日志。
- 取消：结束进程树，删除该任务产生的 `.part` / `.ytdl` 临时文件。
- 解析预览：`python -m yt_dlp -J --flat-playlist <链接>`（带上用户选的 Cookie 来源），超时 60 秒。

### app.py 接口

| 接口 | 作用 |
|---|---|
| `GET /` | 页面 |
| `GET /api/schema` | 参数表单描述 |
| `POST /api/preview-command` | 表单 → 命令行预览 |
| `POST /api/probe` | 解析链接信息 |
| `POST /api/tasks` | 新建下载任务 |
| `GET /api/tasks` | 任务列表 |
| `GET /api/tasks/<id>/events` | SSE：进度和日志 |
| `POST /api/tasks/<id>/cancel` | 取消任务 |
| `GET /api/files` | `downloads/` 中的文件列表 |
| `GET /files/<name>` | 播放/下载成品（只允许 `downloads/` 内的文件） |
| `POST /api/open-folder` | 在资源管理器中打开 `downloads/` |

- 任务保存在内存中，后端重启后清空；成品文件不受影响。
- 端口默认 8765，被占用时自动换一个空闲端口再打开浏览器。

## 页面

从上到下四块：

1. **常用区**（中文，手工设计）
   - 输入框：支持粘贴链接、整段分享文字（自动提取其中的 http(s) 链接）、多个链接（每行一个）。
   - 「解析」：显示封面、标题、作者、时长；合集则列出所有条目，可勾选（转换为 `-I` 参数）。
   - 画质：最佳 / 1080p / 720p / 只要音频（mp3）。
   - 开关：下载字幕、嵌入封面、嵌入元数据。
   - Cookie 来源：不用 / Edge / Chrome / Firefox（选中时提示「请先关闭该浏览器」）。
   - 「下载」按钮。
2. **高级设置**（自动生成，默认折叠）：搜索框（按参数名和说明搜）；17 组可折叠；改动过的参数高亮；每组「重置」。常用区与高级设置共用同一份表单状态，任一处修改另一处同步。
3. **命令预览**：实时显示等价命令行，「复制」按钮。
4. **任务区**：每个任务一张卡片（标题、进度条、速度、剩余时间、状态、取消、展开日志）；完成后可播放或打开文件夹；下方是 `downloads/` 已有文件列表。

## 出错处理

| 情况 | 页面表现 |
|---|---|
| 链接不支持 / 打不开 | 显示 yt-dlp 原始报错 + 中文解释 |
| 403、需要 Cookie | 提示在常用区选择浏览器并先关闭该浏览器 |
| 读浏览器 Cookie 失败 | 提示关闭浏览器后重试 |
| 参数值不合法 | 显示 yt-dlp 的报错，并高亮报错中提到的参数 |
| 需要交互输入（如密码） | 立即失败，提示在高级设置中填写 `--password` 等参数 |
| 解析超时（60 秒） | 提示超时，可重试 |
| 端口被占用 | 自动换端口 |

中文解释按报错关键字匹配（如 `HTTP Error 403`、`cookies`、`Unsupported URL`），匹配不上时只显示原文。

## 测试

自动测试（pytest，不联网），放在 `webui/tests/`：

- `options_schema`：参数总数与 `create_parser()` 一致（扣除隐藏项）；17 组都在；每种类型各取一个参数验证映射；隐藏项不出现。
- `runner.build_args`：默认值不输出；勾选框、下拉、多值输入的转换；含空格和 `&` 的链接保持为一个参数；内部固定参数正确追加；用户自填的 `-P` / `--ffmpeg-location` 不被覆盖。
- `runner` 进度解析：用 yt-dlp 真实格式的 `WEBUI_PROGRESS` 行样本验证。
- 取消：用一个长时间运行的假子进程验证进程被结束、临时文件被删。
- 分享文字提取链接：抖音分享文案样本。

真实验证（内置浏览器）：解析一个 B 站或 YouTube 链接 → 选 720p → 下载 → 进度走完 → 页面内播放；在高级设置中搜索并修改一个参数，确认命令预览同步变化。需要读取浏览器 Cookie 的站点由用户本人操作。
