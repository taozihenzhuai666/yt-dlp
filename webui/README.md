# yt-dlp 网页版

在自己电脑的浏览器里用 yt-dlp：粘贴链接、选画质、点下载，所有命令行参数也都能在页面上设置。只在本机运行（`127.0.0.1`），不对外开放。

## 怎么启动

- 双击 `webui\启动网页.bat`，浏览器会自动打开页面；关掉黑色窗口就停止。
- 或者在仓库根目录运行：`python -m webui.app`

需要 Python 3.10+ 和 Flask（`pip install flask`）；ffmpeg 用 `imageio-ffmpeg` 自带的（`pip install imageio-ffmpeg`），用于合并画面和声音、转 mp3、嵌入封面。

## 页面上有什么

1. **常用**：粘贴链接或整段分享文字 →「解析」看封面、标题、时长（合集可以勾选要下载哪几个）→ 选画质、字幕、封面、Cookie →「下载」。
2. **命令预览**：当前设置等价的 yt-dlp 命令，可以复制到终端直接运行。
3. **高级设置**：yt-dlp 的全部参数，按分组折叠，可搜索；改过的参数会高亮，每组可以一键重置。常用区和这里是同一份设置。
4. **任务**：每个下载一张卡片，显示进度、速度、剩余时间，可以取消、看日志；完成后可以直接播放。
5. **已下载**：`downloads\` 文件夹里的文件，可以播放或打开文件夹。

## 常见问题

- **抖音等网站报「需要 Cookie」**：在「Cookie 来源」里选你常用的浏览器，并**先完全关闭这个浏览器**再下载。
- **端口 8765 被占用**：会自动换一个端口，以黑色窗口里显示的地址为准。
- **文件在哪**：仓库根目录的 `downloads\`；在高级设置里改 `-P, --paths` 可以存到别处（存到别处的文件不能在页面里播放）。
- **刷新页面**：正在进行的任务不会丢；但关掉黑色窗口（停止服务）后任务列表会清空，已下载的文件不受影响。
