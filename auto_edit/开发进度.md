# 自动剪辑：开发进度

在 yt-dlp 的基础上加一套「自动剪辑」工作流，把口播 + 录屏剪成秋芝 2046 那种风格的视频，用来做 FDE（前线部署工程师）知识科普、学习记录和项目开发记录。

> 说明：本目录是独立模块，不改 yt-dlp 本身的代码。`master` 分支保持与官方同步，开发都在 `auto-edit` 分支。

## 2026-10-14

### 已完成

- Fork 官方仓库到 `taozihenzhuai666/yt-dlp`，`upstream` 指向官方，可用 `git pull upstream master` 同步。
- 用本仓库下载了参考视频（抖音 · 秋芝2046《一站式创作 Agent》，10 分 36 秒，1024×576）。
  - 抖音直接下载会 403，要求带新鲜 Cookie；用 `--cookies-from-browser edge` 可解决（运行前先关闭 Edge）。
- 装了 `imageio-ffmpeg`，ffmpeg 位于 Python 的 `site-packages\imageio_ffmpeg\binaries\` 下，没加进系统路径，yt-dlp 要加 `--ffmpeg-location` 才能用。

### 参考视频的风格拆解（目标成品的样子）

全片约 116 次镜头切换，平均约 5 秒一切。

| 元素 | 样子 | 自动化程度 |
|---|---|---|
| 口播主画面 | 真人对镜头，紫色灯光背景，开头和结尾都用 | 全自动 |
| 录屏 + 圆形头像 | 讲到操作时切全屏录屏，人缩成左下角圆形画中画（竖屏版需重新排位） | 全自动 |
| 底部字幕 | 白字黑描边，一句一条，关键词标黄 | 全自动（关键词由 AI 挑） |
| 左上角章节标签 | 绿底黑字，逐个叠加，提示当前讲到哪一章 | 全自动（AI 分章节） |
| 插入画面 | AI 动画片段、Logo、全屏大标题卡片 | 半自动 |
| 节奏 | 无停顿、无口误 | 全自动 |
| 包装 | 片头钩子、片尾号召、花字 | 模板化 |

### 已确认的需求

- 素材：**一条口播录像 + 自学/开发时同步录的屏幕**（录屏时**不说话**）。
- 口播是事后单独录的，录屏远长于口播，大部分录屏会被剪掉。
- 成品画幅：**竖屏 9:16（1080×1920）**，不做横屏。参考视频是横屏，版式要改成竖屏：录屏放在上半部分或缩放后居中，口播头像、字幕和章节标签重新排位。
- 难点：把**不说话的录屏**和口播内容自动对上（只能靠 OCR + AI 看图 + 时间顺序）；另外横屏录屏放进竖屏后字会很小，要裁剪或跟随放大操作区域。

### 候选方案（未定）

1. **AI 出剪辑方案 → 人工过目 → ffmpeg 自动出片**（目前倾向这个）
2. 全自动一条命令出片（以后作为 1 的免确认模式）
3. 生成剪映草稿，最后在剪映里精修
   - 电脑上装的是剪映专业版 10.0；6.0 以后的版本草稿文件加了密，需先做小验证，确认程序生成的草稿能否被打开。
   - 剪映没有开放接口，只能「生成草稿文件」或「操作界面」两条路。
